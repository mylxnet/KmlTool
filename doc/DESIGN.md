# 设计方案（DESIGN）

## 1. 开发目的

用户需要上传 KML / KMZ（如无人机测绘、地块调查导出的数据），在**最新最清晰的卫星影像**上查看定位，并查看要素的**名称、周长、面积**等详情。要求开箱即用、无需安装环境。国内访问可用性优先：默认 Esri 卫星图，并提供高德卫星图与高德普通地图一键切换。

## 2. 技术栈与选型理由

| 选型 | 备选 | 理由 |
| --- | --- | --- |
| Leaflet 1.9.4 | OpenLayers / MapLibre GL | 轻量、瓦片渲染简单、弹窗交互成熟；纯静态可用 |
| Esri World Imagery 底图 | 高德卫星 / 天地图 / Google | 官方免费公开瓦片、影像清晰度顶级（Maxar/Airbus 拍摄）、无需注册密钥。**默认底图**，由用户裁决选定 |
| 高德卫星底图（可选） | 天地图 | 国内访问快，作备选卫星底图；但瓦片为 GCJ-02 坐标系，需要偏移纠偏 |
| 高德普通地图（可选） | 天地图矢量 | 非卫星的路网地图（webrd 瓦片，自带注记，GCJ-02 同套纠偏），适合查看道路与地名 |
| 天地图注记（可选） | Esri 参考注记 / 高德注记 | Esri 影像乡村地名稀少；天地图为 CGCS2000（≈WGS84），注记可直叠无偏移；高德注记为 GCJ-02 偏移不可用 |
| JSZip 3.10.1 | 自行解析 zip | KMZ 即 zip 压缩包，JSZip 成熟、MIT 许可 |
| @tmcw/togeojson 5.8.1 | 自写 KML 解析器 | 社区标准库，输出 GeoJSON 并带样式属性 |
| Turf.js 6.5.0 | 平面几何自算 | 椭球面（WGS84）面积/周长/中心点计算，与专业 GIS 结果一致 |

所有库**本地化存储**于 `static/libs/`（国内源 npmmirror 下载），页面零构建、零外部 JS 依赖。

## 3. 项目结构

见 README「📁 项目结构」。核心三件套：

- `index.html`：页面骨架（工具条 / 侧栏 / 地图 / 首页主题面板 / 加载层 / 提示消息）
- `static/js/app.js`：解析 → 建模 → 渲染 → 交互 全流程
- `static/css/app.css`：工具条 + 半透明侧栏浮层 + 选中信息卡（紧凑备注区）样式

## 4. 功能设计

### 4.1 数据链路

```
文件(.kml/.kmz)
  → arrayBuffer
  → [KMZ] JSZip 解压 → 优先 doc.kml，否则第一个 .kml
  → 编码识别（XML 声明 → UTF-8 → 乱码检测 → GB18030/GBK 兜底）
  → DOMParser → toGeoJSON.kml() → FeatureCollection
  → buildRecords()：每个几何生成一条记录（MultiGeometry 拆分、编号；默认勾选、存净化后纯文本备注；首尾闭合的线转为面几何）
  → 每条记录：turf 计算面积(m²)/周长(m)/中心点，解析 KML 样式
  → 每条记录渲染为一个 L.geoJSON 图层，加入文件级 L.featureGroup
  → 渲染坐标 = displayGeom(原始坐标)：高德底图时 WGS84 → GCJ-02，Esri 时原样
  → applyVisibility()：按 文件显隐（眼睛）→ 勾选（checkbox）/ 筛选（filter）决定图层增删
  → 侧栏渲染列表（只列面要素），地图 fitBounds 定位（缩放封顶）
```

### 4.2 底图管理与坐标系纠偏

- **三种底图**：Esri（`arcgisonline.com`，默认，maxZoom 18）、高德卫星（`webst0{1-4}.is.autonavi.com` style=6 卫星 + style=8 注记，maxZoom 18）、高德普通地图（`webrd0{1-4}.is.autonavi.com` style=8，自带注记，maxZoom 18）；六个瓦片层（三底图 + Esri 注记 + 天地图注记）常驻创建，`applyTiles()` 按 `state.basemap ∈ 'esri'|'gaode'|'gaode-vec'` 与 `state.labels ∈ 'tdt'|'esri'|'off'` 增删；选择写入 `localStorage.kmlBasemap` / `kmlLabels`。Esri 乡村区域 19 级仅有「Map data not yet available」占位图，故统一封顶 18（实测：占位图约 2.5KB，18 级影像 13–15KB）
- **GCJ-02 纠偏**：高德两类底图均为火星坐标，KML 是 WGS84。渲染前 `displayGeom()` 对 Point/MultiPoint/LineString/MultiLineString/Polygon/MultiPolygon 递归做 `wgs84ToGcj02()`（标准算法：a=6378245.0、ee=0.00669342162296594323，中国范围外 [72.004,137.8347]×[0.8293,55.8271] 不转换，高度维保留）。不做纠偏高德模式下要素会偏移约 300–500 米
- **切换重渲染**：切底图时 `rerenderFeatures()` 重建全部要素层（新坐标体系）并恢复选中状态；计算（面积/周长/中心）始终基于原始 WGS84 几何，不受显示坐标影响

### 4.3 关键计算口径

- **面积**：`turf.area()`，WGS84 椭球面面积，单位平方米；多面为各面之和；闭合线转面后同样计算
- **周长**：面取**外边界**环长度（多面为各面外边界之和），线取总长度；点无周长
- **闭合线**：首尾重合（≤1 米）判定为面，几何转为 Polygon 后参与上述面积/周长/中心计算
- **中心**：`turf.centroid()`；点即自身坐标，MultiPoint 取均值
- **单位换算**：1 公顷 = 10,000 m²；1 亩 = 666.6667 m²；1 km² = 10⁶ m²

### 4.4 选中 / 取消选中状态机（点击即弹卡 + 同色加深）

```
未选中 ——点击要素/侧栏行——→ 选中
  ↑                            ├─ 同色加深覆盖层（面=深色半透明、线=加粗、点=加深圆点，无白边）
  │                            ├─ 信息卡立即弹出并保持
  │                            └─ 侧栏对应行高亮
  └———— 取消：再点同一要素 / 点地图空白 / Esc / 信息卡 × / 隐藏、移除其文件 / 清空 / 被筛选排除
```

- 选中实现：`setSelected(rec)` 记录 `state.selected`，`ensureHalo(rec)` 在文件组内插入同色加深层——`darkenHex(原色, 0.7)` 压暗后整体覆盖：面为深色半透明填充（0.5–0.7），线为线宽 +2、同色加深，点为半径 10 的加深圆点；覆盖层 `interactive:false` 不拦截点击，`bringToFront` 置顶；侧栏行加 `selected` 类。**不隐藏其他要素**
- 点击即弹卡：`bindPopup` 后 `layer.off('click', layer._openPopup)` 拆除 Leaflet 自带的点击弹卡，改由选中流程统一 `openPopup()`；点击已选中要素则取消选中
- 点击居中：地图点选或侧栏单击地块后，`centerOnRecord(rec)` 对 `type==='面'` 执行 `flyTo(外接矩形中心, 当前 zoom, 0.6s)`，地块中心落到屏幕中央、缩放不变；点、线不移动地图；底图切换恢复选中不走该逻辑
- 双击侧栏行仍走 `flyToBounds`（定位并按合适级别缩放），会覆盖单击时的居中动画
- 无悬停提示：v1.0.3 删除全部 `bindTooltip` 与 3 秒计时，悬停只做高亮（线宽 +2、填充加深、行同步），不弹任何浮层
- 取消实现：`clearSelected()` 移除覆盖层、关信息卡、侧栏行取消高亮
- 要素层 `bubblingMouseEvents: false`：点要素不冒泡到地图，地图空白点击才能可靠地触发取消
- 信息卡关闭（`popupclose`）联动取消，但仅当图层仍在地图上时生效——底图切换重建时旧图层移除也会触发 popupclose，不应误清选中
- 切换底图后 `rerenderFeatures()` 恢复选中态；切换前信息卡若已打开，重建后自动重开
- 面积单位切换只调用 `setPopupContent()` 原地刷新（打开状态 Leaflet 即时重排），避免关卡/开卡导致 popupclose 误清选中

### 4.5 闭合线按面处理

- 判定：`closedRingOf(geom)` 仅针对 LineString，点数 ≥ 4 且首尾 `turf.distance` ≤ 1 米时转为 Polygon（`coordinates: [c]`，不改原始坐标）
- 效果：类型显示「面」、计算面积与周长、填充线色 25% 透明、列入侧栏并可勾选 / 筛选；线要素没有填充定义，直接用线色做半透明填充
- 兼容场景：部分测绘软件（如「闭合线示例.kmz」）用闭合线画地块边界而不输出 Polygon
- 非闭合线、点仍只上图、不进侧栏；筛选命中时仍显示

### 4.6 显示规则引擎（勾选 + 筛选）

```
recVisible(rec) = 文件眼睛可见 && (筛选激活 ? matchesFilter(rec) : rec.checked)
```

- 每个地块默认 `checked: true`（全部显示）；勾选框变化 → 更新 `rec.checked` → `applyVisibility()`
- 筛选框输入 → `state.filter` 存小写关键字；`matchesFilter` 把名称、净化后备注、类型、文件名、格式化周长/面积/中心坐标与原始数值拼接后做子串匹配
- 筛选**临时覆盖**勾选状态：命中即在地图显示（含点、线），未命中隐藏；侧栏只列命中的地块行，统计显示「匹配 N 个地块」；清空筛选恢复勾选状态
- `applyVisibility()` 统一增删图层（每次全量遍历，文件组按可见性整体增删）；选中的要素被隐藏时自动取消选中

### 4.7 界面

- 顶部工具条：品牌「卫星图」（配置 `siteName` 时显示「<站点名>卫星图」）+ 上传按钮 + 清空按钮 + 底图下拉（Esri 卫星图 / 高德卫星图 / 高德普通地图）+ 面积单位下拉 + 注记来源下拉（天地图注记 / Esri 注记 / 不显示）
- 左侧栏（有地块时出现，半透明 + 毛玻璃）：统计行「N 个地块」/「匹配 N 个地块」+ 筛选输入框 + 文件分组（文件名+地块数、眼睛=显隐、垃圾桶=移除）+ 地块行（勾选框 + 色块 + 名称）
- 空状态：居中半透明主题面板（`rgba(255,255,255,0.45)` + 毛玻璃、`pointer-events:none` 不挡地图）——大字「卫星图 KML 定位查询」（配置 `siteName` 时前置站点名）+ 操作提示 + 署名「v1.0.11 by Mr lin」；无选择文件按钮
- 清空复位：「清空」移除全部文件组、取消选中、清筛选框后，`flyTo(HOME_VIEW.center, HOME_VIEW.zoom, 0.8s)` 平滑飞回初始全球视野（`[34,108]` 4 级），空状态主题面板重现；底图、注记来源、面积单位等偏好保持不变
- 信息卡（半透明深色、带 ×）：名称、类型、周长、面积、中心坐标、净化后的备注；点击选中立即弹出并保持，无悬停提示层
- 备注区紧凑模板：剥离 `style/bgcolor/color/width/height/border/align/...` 等表现属性后，表格统一为透明底、文字继承信息卡颜色、1px 半透明细分隔线、`padding:2px 6px`、细滚动条
- 交互：悬停仅高亮（线宽 +2、填充加深、列表行同步）、单击地块居中并弹卡（点/线只弹卡不移动）、双击侧栏行定位（`flyToBounds` 带 `maxZoom` 封顶：Esri / 高德均 18）、单位切换原地刷新信息卡
- 署名：右下角「v1.0.11 by Mr lin」

### 4.8 注记层（天地图）

- **动机**：Esri World Imagery 在乡村几乎无地名，用户需要镇、村、社名与主干道名
- **选型**：天地图透明注记 `cva_w`（WMTS，球面墨卡托，`t{0-7}.tianditu.gov.cn`，8 子域轮询）；坐标系为 CGCS2000（≈WGS84），可与 Esri 影像直接叠合无偏移。高德 / 腾讯注记为 GCJ-02，与 Esri 影像偏 300–500 米且栅格无法平移纠偏，不采用
- **tk**：天地图「浏览器端」密钥（服务端校验 UA / Referer，白名单可留空），本地放项目根目录 `config.js`（`window.KML_CONFIG.tiandituTk`，不入库；Docker 构建时注入），`app.js` 读取后赋给 `TIANDITU_TK`；留空则不创建注记层，下拉中该项禁用并回退 Esri 注记
- **缩放策略**：注记层 `maxZoom: 18`、不设 `maxNativeZoom`，18 级按天地图原生 18 级注记显示，字号与低级一致、不放大。实测乡村 18 级注记仅零星 POI（数据本身如此），曾试 17 级放大沿用（v1.0.4），因字号变大已取消（v1.0.5）
- **作用范围**：仅 Esri 卫星图；高德卫星 / 高德普通地图仍用高德自带注记
- **数据现实**：天地图乡村注记本身稀疏（17 级约 7/25 瓦片有内容），空瓦片为 213B 透明图，不影响影像显示

## 5. 容错设计

| 场景 | 处理 |
| --- | --- |
| 非 KML/KMZ 文件 | 忽略并提示数量 |
| 非法 XML | 报错提示（编码兜底后仍失败才报） |
| KMZ 内无 .kml | 明确报错 |
| 空 KML（无要素） | 报「没有可显示的地理要素」 |
| GBK/GB18030 编码 | 自动识别解码 |
| 备注含恶意 HTML | 白名单净化（移除 script/iframe/img/事件属性等），并剥离 style/bgcolor 等表现属性 |
| 备注为闭合线画的边界 | 自动按面处理（填充 + 面积周长 + 侧栏） |
| 首尾未闭合的线 | 仍按线渲染，只上图不入侧栏 |
| 大文件 | 全屏加载层提示「正在解析…」 |
| 重复上传同名文件 | 各自独立分组，不互相覆盖 |
| 选中后隐藏/移除其所在文件 | 自动取消选中并恢复其余要素显示 |
| 选中后被筛选排除或取消勾选 | 自动取消选中 |
| 高德模式下中国范围外要素 | GCJ-02 不转换（境外无偏移） |
| 未配置天地图 tk | 「天地图注记」选项禁用并回退 Esri 注记，其余功能不受影响 |
| 天地图注记瓦片为空 / 加载失败 | 空瓦片为 213B 透明图，不报错；tk 失效时仅注记缺失，影像与地块不受影响 |

## 6. 代码审计要点

1. `sanitizeHtml()` 是唯一允许把 KML 内容写进 innerHTML 的入口，白名单外的标签、`on*` 属性、`javascript:` 链接一律剥离；
2. 所有用户可见文本（名称、文件名、报错）一律 `textContent` 赋值，不走 HTML；
3. 信息卡内容用 DOM API 构建，函数返回元素而非 HTML 字符串；
4. 编码检测基于 XML 声明 + U+FFFD 乱码启发式，双层兜底；
5. 路径穿越：本地预览服务（`scripts/serve.js`）对 URL 做 `path.normalize` 后校验必须位于项目根目录内；
6. 选中覆盖层 `interactive:false`，不拦截点击；要素层 `bubblingMouseEvents:false`，避免点要素触发地图空白取消；
7. 备注净化除标签/事件外，还剥离表现属性，防止恶意样式覆盖信息卡或撑破布局。

## 7. 打包分发

纯静态站点，无构建。分发即拷贝整个目录（或仅 `index.html` + `static/`）。本地预览：`node scripts/serve.js`。
